Фототаблиця (веб-версія / PWA) — огляд останків
==============================================

Формує Word-файл «Фототаблиця <№ тіла>.docx» за зразком:
- шапка «Додаток до протоколу огляду» з таблицею (місце дослідження, № тіла, дата, ФОТОТАБЛИЦЯ);
- фото з підписами «Фото №1: …», з можливістю об’єднувати кілька фото в групу зі
  спільним підписом («Фото №3, 4: …», «Фото №7, 8, 9: …»);
- таблиця підписів спеціалістів (№ / ПІБ / Підпис) наприкінці документа.

Файли для публікації на GitHub Pages: index.html, style.css, app.js, docx.js, sw.js,
manifest.webmanifest, папка icons. Усе лежить у корені репозиторію.

Як опублікувати:
1. Створіть репозиторій і завантажте ці файли в корінь (збережіть структуру папки icons).
2. Налаштування репозиторію -> Pages -> Source: гілка main, папка /(root).
3. Відкрийте видану адресу на телефоні -> «Додати на головний екран» (працює як додаток,
   офлайн теж, чернетка зберігається автоматично).
